# BIM-Undergrad-Project
This is a collection of Python code used for Max Bruggman's 2024-2027 Micropaleontology/Oceanography project at Eastern Illinois University.

Hello!

This is the Python code I used for my Micropaleontological project involving benthic foraminiferal counts from the Southern Tasman Ocean. This project took place on and off over the course of my undergraduate career at Eastern Illinois University from 2024 - 2027, where I have gained experience in picking and identifying the individual specimens, using Python to implement complex statistical methods (PCA), and writing academically. Right now I am in the tail end of this project, hoping to get a manuscript published in a local, minor journal (Geocene). I have presented this research and the statistical analysis at the GSA Triple Section Meeting held in Memphis, Tennessee in March of 2026.
